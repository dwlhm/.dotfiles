# AI Knowledge Base

Shared, curated, verified facts so every agent has the same baseline and does not re-verify the same APIs each session.

## How to use

1. Scan the index below and read only the file you need — never load the whole directory.
2. If a fact is missing, verify it once (build, run, or read source), then append it here.

## Index

## Contribution rules

- Only add **verified** facts (built, tested, or read from source); no guesses.
- Keep files compact and high-signal: code snippets and gotchas, not tutorials.
- One topic per file; update this index when adding or renaming files.
