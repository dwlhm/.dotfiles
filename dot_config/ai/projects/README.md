# Project Context

Per-project context, centralized so project repos stay clean of agent files.

## How to use

Before working in a project, match the current directory (or an ancestor) against this index and read the linked file first.

| Project path | File |
|---|---|
| `~/project/dashd` | `dashd.md` |
| `~/project/term` | `term.md` |

Rules: only verified facts; one file per project; update this index when adding files.
