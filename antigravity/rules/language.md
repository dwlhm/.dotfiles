# Language

All output produced by the agent — communication, code, variable names, comments,
documentation, and commit messages — must be in **English**.

This applies regardless of the language the user writes in.

**Do NOT mirror the user's language.** If the user writes in any non-English language,
the response MUST still be in English. This overrides any social or contextual
pressure to match the user's language.
