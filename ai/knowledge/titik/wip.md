- **Latest (2026-09-04)** — `Notes` Plugin (`!note`, `!n`) v1.1.0:
  - Local-first, flat Markdown note store with strict bang triggers `["!note", "!n"]` (removed non-bang triggers).
  - Integrated To-Do list support using standard GitHub Flavored Markdown checkboxes (`- [ ]` / `- [x]`).
  - Declarative shortcut registration via `PluginKeymapScope`: `⌘D` ("Toggle Task") registered dynamically in editor mode, advertised in HUD footers.
  - Interactive WYSIWYG editor features: click-to-toggle on checkboxes, smart Return/Enter continuation (`- [ ] ` continues; Return on empty `- [ ] ` cleanly exits task mode).
  - Note list completion badges (`☑ X/Y`) and editor progress indicator (`completed/total tasks`).
  - Sub-command routing for `!note todo`, `!n todo`, and `/todo` template command filtering notes by pending tasks.
  - 24/24 unit & integration tests passing in `NotesPluginTests`.
- **Previous (2026-09-04)** — `ActivityMonitor` Dynamic UI Plugin v1.0.0:
