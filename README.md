# dotfiles

Personal AI-assistant configuration: one canonical source, multiple harness adapters.

## Structure

```
~/.dotfiles/
└── ai/
    ├── core/             # Engineering rules + orchestration protocol (harness-agnostic)
    ├── skills/           # Canonical skills (frontmatter + pure prompt)
    ├── agents/           # Canonical agent bodies (pure prompts — NO frontmatter)
    ├── adapters/         # Harness entry files only
    │   ├── opencode/     #   AGENTS.md, opencode.jsonc, plugin/, skills/
    │   └── antigravity/  #   GEMINI.md, hooks/, hooks.json, mcp_config.json
    ├── knowledge/        # Per-project persistent knowledge base
    └── scripts/          # sync.sh — pointer-stub generator
```

## Machine config wiring

| Adapter | Wiring |
|---|---|
| opencode | `~/.config/opencode/{AGENTS.md,opencode.jsonc}` and `plugin/` symlinked into the repo; `~/.config/opencode/agent/` generated by `scripts/sync.sh` |
| antigravity | `~/.gemini/GEMINI.md` and `~/.gemini/config/{hooks,hooks.json,mcp_config.json}` symlinked into the repo; `~/.gemini/config/agents/` generated by `scripts/sync.sh`; `config.json` is a real machine-specific file |

Runtime-managed, not tracked (see `.gitignore`): `ai/adapters/antigravity/{config.json,plugins/,projects/,sidecars/,.migrated}`.

## Setup on a new machine

1. Clone the repo (e.g. to `~/.dotfiles`).
2. Install mandatory dependencies:
   ```sh
   brew install fzf
   ```
3. Run `ai/scripts/sync.sh` to generate agent stubs and inline core rules.
4. Create the symlinks listed in the wiring table.
5. Restore machine-specific files (`ai/adapters/antigravity/config.json`) or let AGY create fresh ones on first run.

## Knowledge CLI (`ai/scripts/kb`)

A low-token, surgical knowledge retrieval tool for both developers and AI agents:

```sh
# JIT project context briefing (< 250 tokens)
ai/scripts/kb context [project]

# List gotcha headlines (< 80 tokens)
ai/scripts/kb list [ecosystem-or-project]

# Fuzzy search gotchas using fzf
ai/scripts/kb search "<query>" [--stack <ecosystem>]

# Surgically fetch a single gotcha (< 100 tokens)
ai/scripts/kb get <ecosystem-or-project> <id>

# Add a new gotcha enforcing Symptom, Cause, Workaround invariants
ai/scripts/kb add --shared macos --title "..." --symptom "..." --cause "..." --workaround "..."
```

See `ai/README.md` for full adapter and knowledge-base documentation.
